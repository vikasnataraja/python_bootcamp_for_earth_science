# Day 5 — Extras

Flexible afternoon / wrap-up day. Possible themes:

1. **Data exploration** — Get a new data file and visualize however you want (no fixed structure). See the worksheet historically used in `Old/Day_9_Data_Exploration/`.

3. **Tooling** — Git and virtual environments, Anaconda/local installation, coding with AI, etc.

Debugging materials and optional large-ensemble notebooks are archived under `Old/Day_8_Debugging/` and `Old/Optional_Large_Ensembles/` (data files intentionally omitted from `Old/`; place any needed NetCDFs in `Datasets/` if you revive those lessons).
